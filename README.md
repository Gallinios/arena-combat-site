# Arena Combat Academy

Site για φανταστική σχολή MMA, Boxing, Kickboxing και Taekwondo.

> Φανταστική επιχείρηση. Όλα τα ονόματα, οι τιμές και τα στοιχεία επικοινωνίας είναι επινοημένα για τις ανάγκες του σχεδιασμού.

## Χαρακτηριστικά

- Εβδομαδιαίο πρόγραμμα με φίλτρο ανά άθλημα και τονισμό της σημερινής μέρας
- Κάρτες αθλημάτων, προπονητών και πακέτων συνδρομής
- Φόρμα δωρεάν μαθήματος που δείχνει τα μαθήματα του αθλήματος που επιλέγεις
- Μοτίβο με τα χρώματα των ζωνών του Taekwondo
- Dark / light mode, responsive

## Τεχνολογίες

HTML, CSS και JavaScript χωρίς frameworks, σε ένα αρχείο. Γραμματοσειρές από Google Fonts.

## Εκτέλεση

Άνοιξε το `index.html` σε οποιονδήποτε browser.
